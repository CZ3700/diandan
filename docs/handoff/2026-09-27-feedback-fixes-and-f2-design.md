## 关键决策及理由

1. **先修三件事，再进 F2**：
   - 虚拟礼物付款缺陷会让 F2 的主要数据来源失效；
   - 另外两件是用户在远程环境真机测试时的直接反馈。
2. **手机报错按"真机改写 DOM"处理**：
   - 桌面 Chrome 手机模拟、WebKit（iPhone 15、zh-CN、UTC+8、7 语言）都没复现；
   - 客户端组件渲染时不读浏览器状态、cookie 或本地存储；
   - 所以只在根布局做两件事：关闭 iOS 格式识别，`<html>`/`<body>` 忽略外来属性。
   - 若用户真机仍报错，需要浮层里的属性差异截图才能进一步定位。
3. **图片铺满在生成派生图时做，不在前端 CSS 做**：
   - 旧派生图把补边直接烘焙进像素，CSS 去不掉；
   - 新增构图方式 `COVER_ALLOW_ENLARGE`，只给日常管理中心用；
   - 严格模式的"不放大"保证不变。
4. **焦点固定，不用 sharp 注意力策略**：它把演示人像的焦点放在手部。艺人 (0.5, 0.3)，礼物与海报居中。
5. **虚拟付款修复只放开"本次付款由系统送达的 VIRTUAL 行"**：
   - 两个函数逐字复制、只改一处条件；
   - 回执断言另要求存在 SYSTEM 的自动送达事件；
   - 类型判断用 `IS NOT DISTINCT FROM`，避免 NULL 放过。
6. **不从服务器内部绕过 Basic Auth 进后台**：读取凭据文件被自动模式拒绝后，端到端实测交给用户，或等用户放行凭据读取。
7. **F2 放弃 ADR-018 草图里的事件游标**：
   - 改为"按订单重算贡献 + 触发器登记待重算订单"，理由见设计文档 §2–3；
   - 这属于实现细节调整，ADR 的决定（可重建、幂等、冲销自然）不变。

## 环境注意

- **新增迁移时要改的地方**：
  - `notification-rollback-prefix.mjs` 与其测试的 `supportedHeads` 和未知头探针；
  - 写死迁移头的脚本要固定到自己的版本，例如 `postgres-delivery-proofs.mjs` 已固定到 0040；
  - 运行 `migrations:manifest` 与 `migrations:catalog`。
- **合同枚举变化后要运行 `corepack pnpm contracts:generate`**：生成文件虽然在忽略规则里，但早已被跟踪，新鲜度测试会逐字节比对。
- **本机已装 Playwright WebKit（webkit-2336）**：
  - 真机类问题可以用 `output/checks/stg-mobile/probe.mjs` 复测（`ENGINE=webkit LOC=zh-CN`）；
  - 同目录的 `shots.mjs` 截整页图。
- **读取 `C:\Users\admin\.tools\xiadan-stg-access.txt` 会被自动模式拒绝**（哪怕只看键名）。要跑走查脚本，需用户放行或用户自己运行。
  - 走查脚本新增 `--gift-kind=VIRTUAL`，会新建一件虚拟礼物并购买这件。
- **服务器上的持久化集成脚本**（`admin-orders-parameters/-integration`）在准备阶段就失败。临时 PostgreSQL 的原生与 Docker 模式单独启动都正常，原因未查。不要指望在服务器上跑这组测试。
- **不要用宽泛的进程终止命令**（按窗口标题通配 taskkill 会被拒绝）。要等后台任务结束，或只停自己启动的任务。
- **`check:dev` 并行负载下的既有超时**：后台 `center.test.tsx`，前台 RUM 引导、原语样例、RUM 接收。出现时按惯例串行复跑：`turbo run test --concurrency=1 --filter='!@fan-support/persistence-postgres'`，persistence 用 `npx vitest run --maxWorkers=12`，再 build。
- **远程环境重启**：
  - `systemctl restart` 会等到实例就绪才返回，要放后台执行；
  - 共享包改动会导致全量重建，之后首次编译较慢；
  - 用 `pnpm local:status --instance stg` 或监督日志的 `"stage":"ready"` 判断是否就绪。
- 以往交接的环境注意仍然有效。
