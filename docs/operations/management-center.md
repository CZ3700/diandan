# 管理中心

默认入口是 `/:locale`，中文入口是 `/zh-CN`。日常只需要这三个栏目：

| 栏目 | 操作 |
| :-- | :-- |
| 艺人 | 点添加，上传照片，填写名字和描述，点添加并显示。已有艺人可直接编辑。 |
| 礼物 | 点添加，上传图片，填写名称、描述、价格，选择分类和礼物类型，再提交。 |
| 首页海报 | 上传图片并替换；在历史记录里选择之前的图片即可恢复。 |

图片自动处理手机和桌面所需尺寸，保留原始比例；小图不放大。提交后显示处理进度，只有发布成功才显示成功。上传失败可重试；处理中不用重复提交，刷新后也能继续查看结果。

礼物类型与库存分开设置。可重复售卖的礼物默认按单准备，无需填写虚构库存；需要限量时展开更多设置，选择真实库位和数量。已有库存账目的销售方式保持固定，仍可编辑内容、价格和库存数量。

描述可以直接用熟悉的语言填写。系统保存实际原文，不要求先翻译七种语言，也不会把原文标成已经翻译。粉丝界面仍支持七种语言。

## 本地开发入口

```bash
mise exec node@24.20.0 -- corepack pnpm preview:management-center
```

命令先构建依赖，启动隔离 PostgreSQL、TLS 对象存储、API、图片处理与两个网页应用，执行真实浏览器回归后，只打开一个管理中心窗口。凭据只保存在当前进程与浏览器的安全 Cookie，不写入页面或输出文件。

这是 `LOCAL_TEST_DEV` 环境，包含测试内容，最多运行 110 分钟；退出会清理隔离环境，不能把它当作正式内容存储。暂停或重启后的正式数据保存、生产账号和部署继续遵循后续阶段的要求。

只执行回归而不保留窗口：

```bash
mise exec node@24.20.0 -- corepack pnpm verify:management-center
```

结果写入 `output/checks/p3-06-management-center/run-*/`：`validation.json` 是本次综合结果，浏览器目录包含实际操作、双端七语言截图和可访问性结果；失败保留安全诊断。日志不得加入表单私密内容、SQL 参数或凭据。

旧政策和专业配置工作台保留在受保护的 `/:locale/advanced`，用于旧严格流程回归；日常中心不需要进入这里。真实支付、生产身份、staging 和生产发布不属于该本地验证结果。
