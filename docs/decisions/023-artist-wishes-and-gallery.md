# ADR-023：艺人专属心愿与自愿公开的心愿展馆

> 状态：Accepted（用户 2026-10-01 授权功能实施，并明确单次完成、付款后展示“已支持心愿”）
> 关联：ADR-005、ADR-011、ADR-019、ADR-022；SPEC §0.8

## 决定

1. 每个 WISH 礼物绑定且只绑定一位艺人。绑定是稳定业务对象，不是通配购买资格或可随文案改写的标签；艺人详情展示其专属心愿，礼物详情固定收礼人。
2. 每个心愿只有一份购买资格，限定一个规格、数量一；复用 TRACKED 库存预占，同时以 gift/wish 级永久唯一支持记录挡住补货、多规格、多市场和并发绕过。绑定后不改送礼对象，不转换成普通礼物重新出售。旧未绑定 WISH 不自动猜测艺人，必须先在后台补齐绑定再恢复购买。
3. 可信支付入账且有效预占提交后记录唯一支持者，关闭购买。浏览器回跳不能创建勋章。既有晚到支付、已释放预占与不确定结果保留资金事实并进入原异常处理，不颁发重复心愿勋章，不吞掉 capture。
4. 付款成功后的勋章统一表示 **Wish supported / 已支持心愿**。WISH 仍走人工准备与送达；送达后可显示交付完成，不冒充付款即送达，不新增众筹/分账/积分/排行榜。
5. 展馆公开由买家主动选择，默认 PRIVATE。另有 PUBLIC_ANONYMOUS 与 PUBLIC_NAMED；公开别名为独立明确输入，绝不从加密私密署名/留言取值。别名限40个Unicode字符、纯文本，不进入日志、分析或URL。未公开的支持也占用心愿资格，并可在安全查单页查看私人纪念。
6. 展馆只展示独立随机纪念ID、公开艺人/礼物快照、支持日期、经同意的别名或匿名称呼与徽章状态。禁止订单号、订单访问token、金额、邮箱、私密留言、support intent ID及内部对象存储key。
7. 买家可经已有安全查单会话撤回公开展示；公开读取实时排除撤回、整行成功退款和拒付败诉记录。部分退款、拒付OPEN/WON不自动撤回，沿既有凭证语义。私有审计历史保留；退款、撤回或恢复历史内容都不自动重开已支持的心愿。
8. 预占在结账时发生；加入购物车不占住心愿。未付款的有效期结束后按已有安全过期规则释放；已有在途/UNKNOWN支付不能凭浏览器超时清除。已公开历史不因礼物改名、价格或照片编辑而改写。

## 架构与兼容

PostgreSQL仍是唯一业务真相源。绑定、订单心愿关联、公开选择与支持历史通过显式schemaVersion合同和现有Application/Port/Adapter边界接入。新字段可选以保持旧请求/回执的序列化与hash；缺省不自动回填或追溯公开历史订单。旧WISH历史订单不自动生成展馆记录。

新增公开页为 `/:locale/wish-gallery`，支持按艺人浏览；艺人页与WISH类型目录提供入口。它是仅含经授权纪念记录的展示墙，没有评论、粉丝账号、聊天或互动排行，构成SPEC禁止公开评论墙规则的有限新增例外。

## 验证要求

必须覆盖同心愿不同购物车并发结账、重复回调、晚到支付、编辑/补库存绕过、错误艺人、数量、非WISH公开选择拒绝、草稿与发布失败原子性、匿名/别名/不公开、撤回授权、退款/拒付、旧订单不回填、旧JSON/hash、迁移有损降级拒绝。完成实际PG及正常鉴权HTTP、七语言双端/键盘/错误/减少动态、check:dev和独立复核；公开TEST部署另按实际连接条件验收。
