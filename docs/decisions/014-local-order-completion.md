# ADR-014 — 商户接入待定期间继续订单闭环本地开发

- 状态：ACCEPTED（2026-09-10，本地开发排期）
- 依据：用户 2026-09-09 明确先完成通用支付接口，商户资料与具体平台对接以后补充；通用接口本地交付后，2026-09-10 要求“继续推进下一阶段”。结合连续开发授权，继续订单闭环，无需重复询问同一商户决定。

P4-04 已验收的 TEST 支付运行时及通用支付合同满足 P4-05 本地开发输入。允许其本地依赖门使用这两项已验证检查点；P4-04 保留 IN_PROGRESS、无 executor，真实商户、具体 PSP adapter/sandbox、小额支付、USDT mapper 与商户配置管理入口仍未完成。此例外不把 P4-04 标为 DONE，不宣称实际收款可用。

P4-05 按 READY → IN_PROGRESS 单独领取，root 独占 Lane A。先冻结合同，再按原子证据应用与库存结算、安全查单、界面三个顺序检查点推进；同一检查点的文件独占并行。各检查点有真实集成和独立复核，只有全部任务验收满足才标 DONE。P4-06 仍等待 P4-05，不同时领取。

P3-06 未完验收、Phase 4 真实 PSP 与七语言验收、Phase 5 入口和生产发布门均保持。仅本地 Git 提交，不推送、不部署、不使用真实资金。回退排期只暂停后续领取，保留已有兼容代码与证据，不破坏历史数据。
