# ADR-013 — 购买闭环本地开发与浏览验收分开排期

- 状态：ACCEPTED（2026-09-08）
- 授权：用户要求加快开发；收到“优先接通购物车→结账→订单，保留性能和人工验收”的提案后回复“继续下一阶段”。这是开发顺序调整，不是验收豁免。

P4-01 的直接依赖 P1-03/04/05、P3-05 均 DONE。P3-06 的移动性能、人工运营计时、读屏和关键译审没有购物车服务端实现的数据依赖，因此允许 Phase 3/4 同时 ACTIVE，仅在本地开展 Phase 4。P3-06 保留 IN_PROGRESS、验收待续且无 executor；本轮 root 只执行 Lane A 的 P4-01。

P4 各任务按直接依赖 DONE → READY → 领取逐个推进，不能同时将整个 Phase 标 READY，也不因该例外改变原验收标准。P3 只有全部原门满足才关闭，P5 的入口须 P3/P4 都退出；真实支付、正式内容、staging 和发布门继续独立。

开发采用 `docs/plan/development-cadence.md`：定向失败测试先行，各文件独占分工，共享合同冻结后并行，受影响真实集成必跑，一个集成候选统一全量检查。本地 Git 提交，按用户既有决定暂不推送。

回退排期时保留已有兼容代码、数据迁移和所有证据，暂停新 P4 任务领取，继续 P3 未完验收；不得通过回滚用户数据或标记假 DONE 回退。
