# ADR-016：剩余任务的逐项本地研发排期

> 状态：ACCEPTED
> 日期：2026-09-22（Asia/Bangkok）
> 决策者：用户；执行协调：Codex `/root`
> 范围：只调整本地开发领取顺序，不降低任务 DONE、真实验收或发布条件。

## 授权与背景

用户先要求“继续按计划完成剩下的2+18项”。项目随后提交 `docs/plan/remaining-delivery.md` 的具体扩大本地排期：先 P5-04，再退款/配置、异常处理、接入手册、基础设施离线部分、P6 本地部分与 P7 准备。用户回复“那就继续按计划推进下一阶段”，确认按该方案持续推进。无需逐项重新询问已获授权且符合下述条件的本地研发。

ADR-015 的 P5-01→P5-02 已全部本地验收；其历史白名单不被改写。本决策是新的排期授权，允许消费经独立验收的直接依赖本地成果，同时保留 P3-06、P4-04 及后续任务的外部验收欠项。

## 首个 READY 任务与依赖依据

本次仅将 P5-04 置 READY，Lane A 空闲、尚无 owner；root 仍须先登记开始时间、精确范围和验证计划再实施。计数为 29 DONE / 2 IN_PROGRESS / 1 READY / 17 PENDING，共 49 项。

- P1-03 已 DONE，既有纯领域选路和确定性测试可直接复用。
- P4-04 的 `output/checks/p4-04-payment-runtime/final-verification.md` 与 `final-independent-review.md` 已验收 TEST 支付能力、PG 配置/健康读取、冻结账户/规则的两事务创建、同键恢复及 UNKNOWN 原账户恢复；不等于首个真实 PSP 已接通。
- `output/checks/p4-04-payment-connectors/final-verification.md` 与 `final-independent-review.md` 已验收通用七操作端口、已部署 adapter 目录、版本化连接投影、受控 HTTPS 和严格关联边界；不是 PG 配置管理/广播，也不是 USDT 专属 mapper 或真实卡网络认证。
- `output/checks/p3-06-h2-matrix/p5-04-readiness-review.md` 已独立核对上述成果与当前源码的适用范围。P5-04 复用现有 capability、Domain routing、PG 约束和 conformance 基础，补实际健康闭环等缺口，不重造已验收框架。

以上只满足 P5-04 的本地开发输入；当前实现仍须重新按自身改动完成失败测试、真实本地集成和独立复核。P4-04 保持 IN_PROGRESS、无 executor，真实商户资料、批准 PSP、sandbox/真实支付及 USDT 专属接入继续保留。

P5-04→P5-03 用于减少共享支付合同反复变动，不增加业务依赖。所有原直接依赖 ID、最低验收和最终阶段退出条件不变。本地实现“完整验收”必须覆盖该任务可本地交付的全部范围，不能用一个局部切片或仅有代码替代。

Phase 6/7 **本次仍 LOCKED**，其任务不一次性 READY。走到对应波次且候选任务的原直接依赖本地成果均通过独立验收后，协调者在 MASTER 与该 phase 明确登记有限本地 ACTIVE 范围、未覆盖项与证据，再将符合 Lane 条件的单一任务置 READY；无需重复请求同一排期授权。LOCKED 状态下不得直接领取。正常路径仍按完整 Phase 退出门推进。

## 状态、证据和交付边界

- 不改变任何既有 DONE；P3-06 的本地 H2/技术复核不代替真人操作、实际读屏、真机、关键译审和正式图片；P4-04 的 TEST 不代替真实 PSP。
- 完整任务只有原验收全部满足才标 DONE。已完成本地范围但待外部验收的任务保持 IN_PROGRESS，列明剩余条件及责任方并释放 executor；经本决策允许的后继只消费明确独立验收过的本地成果。
- 每次领取一个 Task ID、每 Lane 一个 executor；先登记范围和验证计划，再合同/失败测试、最小实现、受影响检查、真实本地集成、质量门、非作者复核与本地提交。旧失败、缓存和未运行范围如实保留。
- 本决策不批准云 apply、真实收付款、正式内容发布、Git push、生产发布或上线观察的代签；不推定品牌、主体、PSP、市场/币种、政策、身份源与服务商选择。真实 sandbox、staging、恢复、灰度和上线后 24/72 小时证据仍按原门完成。
- 保持一个简单管理中心，艺人/礼物短表单、海报替换与历史恢复。沿用 SPEC §9.0/ADR-012 的真实原文发布、lang/noindex 与后补翻译；政策、支付、订单、邮件和关键 UI 的严格批准要求不变。P7 导入工具不是日常上传的新增前置步骤。

本排期随可验证输入逐项推进；若外部资料到位，回到原任务补齐验收。停止或调整后续领取不删除兼容实现、历史迁移、数据或证据，不做破坏性回退。
