# P5-05 支付配置管理实施与验收

基线：`fb89c3a`。Owner `/root`，Lane C；授权与状态以 Phase5 执行登记为准。

## 产品范围

同一管理中心新增支付设置：选择已部署账户，编辑启停、名称/提示、排序、灰度和明确的国家/市场/币种/金额规则；健康参数收在高级设置。保存草稿、七语独立审核、检查差异、确认发布；历史配置可预览后回退。只配置部署过的 adapter，不接收代码或连接秘密。新商户身份、接口地址及密钥引用由受控部署初始化为新的不可变账户；本页不声称已完成实际商户接入。

新草稿不可覆盖；源语言修改后的旧译文必须重新编辑和审核，英文同样不可自审。普通艺人/礼物/海报上传沿用原文直接发布，不因支付文案的审核要求增加步骤。

仅调整规则而未改文案时，可沿用同一账户、曾实际发布的管理版本中完全一致的英文源及各语言批准证据。数据库保存不可变复制凭证，保留原作者、审核人和审核时间；不生成新的人工批准记录。改动过的文本、不同账户、未发布草稿或未指定来源均不能继承批准。

## 合同和责任

- root：独立配置/持久化/校验合同、纯领域校验与差异、OpenAPI、旧合同保护、统一质量门、文档与本地提交。
- persistence：0036、管理配置仓储、当前授权、永久幂等收据、审核/验证、canonical publication/head/outbox、健康策略激活和 PostgreSQL 验证。
- runtime：application/API、真实部署 gateway 目录、每实例自动传播、动态健康策略、HTTP/多进程与旧付款退款恢复验证。
- admin：现有管理中心入口、BFF、七语表单、差异/历史/二次确认和浏览器验证。

不并行修改历史迁移、已有合同根、根锁文件或同一入口。旧版本没有管理草稿/健康历史事实时，不编造历史；初次创建明确的新管理版本，回退只消费实际管理发布历史。

## 验收清单

1. 非法金额、空规则、未部署账户/不支持方式、缺译/未审/过期译文、自审拒绝；零灰度是合法停新流量方式。
2. 权限、MFA、CSRF、当前 head、验证摘要及部署能力在实际写事务重验；失响应同键只产生一次发布、审计和 outbox。
3. PostgreSQL 管理草稿、批准与发布证据不可变；回退生成单调的新 publication generation，恢复旧值时健康策略亦使用新版本。
4. 两个独立 Node API 进程自动读取同一 PostgreSQL 投影，发布和回退均≤60秒；重启重建、刷新失败、旧 probe 迟到均有证据。
5. 既有 UNKNOWN 付款和退款仍使用原账户/原幂等键，配置变动不再收费或重复申请退款。
6. 七语言 390×844 / 1440×900，键盘、错误、空状态、reduced-motion、断响应恢复；查看真实截图。
7. 受影响测试、format/lint/typecheck/build、相关实际集成、旧合同/迁移/未跟踪保护、秘密扫描及独立 S.U.P.E.R 复核。

原始失败、缓存命中与没有执行的范围须保留。正式商户能力、关键文案人工批准、实际身份/密钥和 staging/生产门不由本地测试替代。
