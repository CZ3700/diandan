# 艺人专属心愿与心愿展馆实施计划

2026-10-01 用户授权；行为见 ADR-023 / SPEC §0.8。进度唯一入口为 launch-progress 的 C-20261001 心愿礼物绑定与心愿展馆。

## 交付流程

1. 后台选择 WISH → 必选一位艺人 → 显示数量一和不可改绑定 → 正常图片/价格发布。
2. 艺人详情看专属心愿 → 礼物页固定收礼人 → 选不公开/匿名公开/独立别名公开 → 数量一购买。
3. 实际可信付款与库存提交 → 心愿停售 → 同一事务留存唯一支持记录 → 经同意的记录进入展馆。
4. 查单页查看支持勋章、送达状态和公开选择，允许撤回公开展示。退款/拒付按ADR-023同步过滤；历史不可重写。

## 实现分工与顺序

- 共享合同先冻结：绑定/public wish summary、管理eligibility联合、cart galleryPreference、公开gallery分页、受保护order wishSupport与撤回命令。旧请求省略新增字段时字节与hash不变。
- catalog_integration_audit：绑定合同/0060、日常发布、目录和购买权威校验、checkout心愿关联；锁顺序与B对齐。
- research_gifts_b：gallery合同/0061、公开选择持久化、可信入账唯一支持、公开查询和受保护撤回、真实PG专项。
- research_gifts_a：后台艺人选择与状态/错误文案、七语i18n文案及相关界面测试。
- root：API/BFF与composition、前台专属心愿/固定对象/公开选择/展馆/查单纪念、合同注册/迁移manifest与catalog、文档及集成验收。共享index和registry由root维护。
