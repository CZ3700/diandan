# 持久本地体验

本地 TEST 环境让前台、管理中心、API 与独立 Worker 使用同一 PostgreSQL 和媒体存储。默认使用本地模拟支付，不扣真实款、不发送外部邮件；本地身份选择页只模拟身份提供商，不能作为生产身份服务。

## 启动和打开

在仓库目录运行：

```sh
mise exec node@24.20.0 -- corepack pnpm local:start --open
```

已激活 Node 24.20.0 时可简写 `pnpm local:start --open`。首次先安装依赖 `pnpm install --frozen-lockfile`。需要可运行的 Docker/Colima、PostgreSQL 18 和 Chrome；macOS 可使用已安装的 `postgresql@18`，其他安装路径通过 `FAN_SUPPORT_LOCAL_POSTGRES_BIN=/absolute/path/to/bin` 指定。启动会先编译依赖，初次初始化 TEST 市场、权限、支付路由和四类政策；重开不替换已发布内容或配置。首次上传艺人后，本地助手以独立 TEST 桌面/手机素材通过正常媒体与七语审核流程建立首张首页，再可在管理中心上传自己的海报替换；已有首页始终保留。

`pnpm local:open` 打开专用 Chrome 内的前台、管理中心和测试收件箱。专用浏览器将保留域名映射到本机，并只信任本实例证书公钥；不改系统 hosts、不安装系统 CA、不关闭全局 TLS 校验。直接将 example.invalid 链接粘贴到普通浏览器不能访问。

## 操作

管理中心点击登录，在明确标记 Local TEST 的身份页选择管理人员。艺人上传图片并填写名字、描述；礼物上传图片并填写名字、描述、价格和分类；首页海报上传替换。礼物类型与库存策略分开，默认按需采购，所有收礼方均为工作室转交艺人。

侧栏“界面语言”可切换全部七种语言；简体中文也可通过同一后台地址的 `/zh-CN` 路径打开。界面语言与表单里的“内容语言”分别设置，不改变礼物价格或币种。

选好新图片，或编辑已有艺人、礼物、当前海报时，可展开“调整图片焦点”，点击原图主体、使用方向键或滑杆调整。艺人提供肖像、电脑海报、手机海报三种裁切预览，礼物一种，海报两种；保存后才从原图重新生成并发布。无需调整时沿用默认或原有焦点。无法追溯原图的旧图片会提示重新上传，不能用已裁切的小图补回丢失的部分。

保存失败时，当前页面保留填写内容和焦点，重试前不要刷新。未保存的编辑在切换语言、刷新、返回、跨工作区或退出时会提示确认；取消离开可继续编辑。已上架礼物的市场与币种不能直接修改，现货仓位也保持原值；仍可修改同一市场、币种下的售价和现货数量。仅调整图片或文字时，不会把打开表单时的旧价格、旧库存写回。

“店铺装修”管理首页区块：上下移动调整顺序，勾选控制显示；海报、艺人和礼物三个核心区块保留。右侧可以切换手机/电脑预览，预览不会购买或改动公开页面。“保存草稿”后才可“发布”；“恢复默认布局”只改变待保存草稿。“发布历史”可恢复以前的布局，并保留最新海报、商品与订单。退出或切换工作区前会提示尚未保存的修改；如果提示版本冲突，先重新载入当前版本再调整。

在“管理中心 → 店铺装修 → 全站主题”选择配色，展开“布局、文字与动效”可调整首页海报“沉浸海报/图文分栏”、礼物“标准网格/大图展示”、动效“标准/轻柔/关闭”和速度“标准/快捷”，还可选择艺人详情“沉浸海报/图文分栏”和礼物详情“图片在左/图片在右”，也保留文字大小、内容留白与圆角。礼物左右布局只用于电脑，手机均先图片后选购内容。右侧可选择首页、艺人或礼物预览，切换手机/电脑并点击“重播预览”；先“保存草稿”，确认后“发布”，也可从“主题发布历史”恢复。预览不改变公开页面。

恢复主题会同时恢复它的外观和动效设置，但保留后来替换的海报、首页区块顺序与显隐、商品和订单。旧主题无需转换，默认仍为沉浸海报、标准网格、艺人沉浸详情、礼物左图和标准动效/速度。“关闭”仅取消装饰动效，加载状态和操作反馈仍保留；设备的减少动态设置始终优先。新打开或刷新页面会使用已发布主题；已打开的页面在站内跳转时保留当前主题，刷新后更新。

“店铺装修 → 导航与页脚”可上下移动顶部链接，调整页脚顺序并勾选需要显示的项目。首页、艺人、礼物、语言、购物车和菜单内的查单入口保留，政策链接不可隐藏；地区入口还受实际市场与币种配置约束。右侧选择顶部、菜单或页脚，检查手机和电脑效果，再保存草稿并发布。导航有单独的发布历史，恢复导航不会恢复主题、首页布局、海报或商品。导航读取最多等待一秒，异常时以 `data-navigation-source="FALLBACK"` 标记默认必要入口；恢复读取后刷新页面即可更新。普通关于、FAQ和客服内容编辑属于后续信息页功能。

预览与真实首页、艺人和礼物详情使用同一套组件，只展示已发布的图片和内容。详情自动采用首个已发布对象作样本；收礼状态、价格和库存以实际配置为准，未上架内容会显示空状态。切换预览页面保留未保存的主题设置，也不改变公开页面。部署时商城必须配置准确的 `FAN_SUPPORT_ADMIN_ORIGIN` 才能启用嵌入预览；本地启动器自动设置。布局读取失败会显示可重试错误，不将默认版式冒充已发布结果。主题是独立的外观读取，最多等待一秒；异常时页面暂用默认外观并标记 `data-theme-source="FALLBACK"` / `data-theme-status="UNAVAILABLE"`，不阻塞支付回跳或查单，不冒充已发布主题。

前台选择艺人、礼物、署名/留言后结账，支付页面明确为 TEST，无须输入卡号。付款结果由服务端签名回调确认。测试邮件进入本地收件箱，使用其中的安全链接查看订单；管理中心可审核留言、准备、送达和按权限退款。独立复核身份用于需要第二人审核的配置和内容流程。

## 停止、重启与状态

```sh
pnpm local:status
pnpm local:stop
pnpm local:start --open
```

停止只关闭本实例进程与容器，保留数据库、媒体和密钥。启动地址与密钥固定，不会因为重启让旧订单的加密内容失效。状态检查四个实际应用，监督进程存活不代表全部健康。单仓库只允许一个本地实例占用 Next 生成目录。更新源码后先停止再启动，以加载新的 API/Worker；全仓 production build 也应先停止本地体验，避免同时修改 Next 生成目录。

私有状态位于 `node_modules/.cache/fan-support-local-experience/default/`，权限目录0700、配置0600。不要删除整个 node_modules、复制配置到公开目录或提交到 Git。完整备份需停止后一起保存该实例目录；仅备份数据库而丢失密钥不能恢复私密留言。此目录是本机开发数据，不替代生产备份和灾难恢复演练。

`--instance <名称>` 可建立独立验收环境。`local:reset --confirm <instanceId>` 是显式清空操作，只接受状态中的完整实例ID，运行中不允许清空；日常无需使用。

## 开发模式提示

默认本地前台使用 Next 开发服务器；当前隔离回归实例使用前台正式构建，后台仍为本地开发服务。私密订单页可能出现红色「1 Issue」调试徽标：已核实为 React 开发版尝试使用 eval 重建调试堆栈，被页面的严格 CSP 拒绝。实际订单查询与操作验收通过，未出现 pageerror；这不等于控制台完全无提示。保留 CSP 防护，未添加 unsafe-eval。生产版 React 没有这段开发探测，但生产部署的浏览器验收仍需单独完成。诊断见本轮 `root/development-csp-note.md`。
