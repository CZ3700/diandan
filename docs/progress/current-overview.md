## 产品与已确认约束

精品艺人礼物商城：浏览艺人 → 选礼物 → 私密留言/署名 → 游客付款 → 安全查单 → 工作室准备并交给艺人。沿用已批准黑金视觉，人物和礼物摄影保持原色。无社区、榜单、积分、众筹、艺人登录、分账或原生App。

默认管理中心以简单上传为主：艺人填图片/姓名/描述，礼物填图片/名称/描述/价格/分类，海报上传替换及历史恢复。日常内容可先显示真实原文；支付、政策、订单与界面仍遵守七语言要求。礼物类型与库存策略分开；按单准备可重复售卖，无需虚构库存，全部由工作室交付艺人。
