# P4-01 cart transport evidence scope

The API uses `POST /api/v1/carts` to establish an empty cart, `GET /api/v1/cart?presentationLocale=…` to read it, and `POST /api/v1/cart/items` to add one line. The browser body never carries a cart identifier or credential. The `__Host-fan-cart` cookie contains 32 random bytes; KMS purpose-separated HMACs authenticate the session and CSRF header. All configured current/historical MAC candidates must succeed before Application is called.

Owned API tests exercise privacy headers, exact origin, strict query/body input, missing/duplicate cookies, CSRF, header-only idempotency, body size, expired-cookie clearing, response identity and lifecycle cleanup. The real HTTP harness uses the normal admin author/review/publish chain, a disposable PostgreSQL database, actual TLS S3 and the image worker. It starts neither Next nor a browser. Its result is not browser Secure-cookie acceptance, AWS KMS acceptance or a production release.

The HTTP cryptography fixture invokes the actual KMS adapter, AES-256-GCM field encryption and decryption, and HMAC implementation. Only remote KMS commands are implemented by a TEST-local authenticated wrapping service. Master keys exist only in memory and are zeroed on teardown; private fields, cookies and CSRF are not written into evidence. Both empty anonymous and private Unicode intents are tested. `cart-http-kms.test.mjs` also proves changed subject/purpose cannot decrypt the field.

Response recovery uses an owned single-request HTTP fault proxy: it waits for the actual add request to complete upstream, then destroys the downstream connection before sending any response headers or body. The client must observe a real network failure and then recover through its previously established cookie and original key. A separate small HTTP test proves that the proxy forwarded exactly once before disconnecting. Concurrent duplicate adds and two independent cookies using one key are separate checks. No checkout, payment, inventory reservation, or live fan data is involved.
