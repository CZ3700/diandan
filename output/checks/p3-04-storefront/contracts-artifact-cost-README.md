The first test currently creates documents once for structural checks, then regenerates and renders twice for determinism. It is possible to parse the first independent render for the structural assertions and retain the second complete independent render, eliminating the extra creation. A separate Node `assert.deepEqual` approximation found shared-reference component comparisons at 1 ms and parsed-object comparisons at 3 ms, plus 29 ms parsing (`contracts-artifact-comparison-cost-review.json`). Actual Vitest equality was not instrumented, so this is only an optimization candidate, not a claimed test-level speedup.

The root decision is to retain the existing test and renderer: the isolated deterministic test is well inside its current budget. Final whole-repository verification will sequence its heavy stages. No timeout increase, cached second render, reduced determinism assertion or skipped old-root comparison is justified by this observation.
