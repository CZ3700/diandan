# 运营验收：操作前读一次

这份说明供接受一次培训的非开发运营人员使用。请等准备人确认环境已实际启动，并交给你本次可打开的操作卡和三个后台窗口后再开始。仅有说明文件、命令或测试通过记录，不代表环境已经可用。

这是本地 TEST，示例礼物和文案不用于真实销售。本次尚没有真人验收通过记录。

## 先认清窗口

- **编辑窗口**：由操作者查找内容、换图、填写资料、保存、导入翻译和提交审核。
- **独立审核窗口**：由另一位审核人检查当前版本，在各语言下批准翻译。操作者不能自己换个窗口就算独立审核。
- **发布／价格窗口**：由有相应权限的操作者设置价格、检查发布条件和发布；这些步骤也计时。
- **操作卡窗口**：查看本次实际材料、复制字段、整理翻译文件和记录开始／结束。顶部按钮只切换已经打开的角色窗口。

开始前先阅读“实际准备的材料”，确认要换的图片、艺人、礼物网址标识、SKU、类型和市场。图片和 ID 以本次动态操作卡为准，不沿用上一次运行的材料。填写匿名代号（例如 OP1），如实勾选已培训、非开发人员。不要提前修改目标、创建礼物、导入或发布来缩短时间。

## 三项任务怎么计时

| 任务             | 点击对应“开始…”后做什么                                                                                       | 什么时候点“结束当前任务”                           |
| ---------------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------- |
| 首页，3 分钟     | 打开当前首页，替换桌面和手机海报，保留原艺人引用，保存并完成提示所需的审核                                    | 在“桌面预览”和“手机预览”中实际看到新海报           |
| 艺人，5 分钟     | 找到操作卡中的 Luna Mira 当前草稿，替换头像／照片，使用材料的全部英文艺人字段，导出、整理、导入七语并完成审核 | 实际确认照片和七语简介的预览结果                   |
| 完整礼物，8 分钟 | 从“新建礼物”开始，完成规格、结构、图文、七语、独立审核、价格、预览和发布                                      | 发布成功，并确认礼物已启用、资料和价格与操作卡一致 |

现有后台按钮叫 **“保存新版本”**，它会保留旧版本，不必寻找单独的“复制草稿”按钮。“检查发布条件”通过后使用 **“发布”**，控件会执行内部验证，不存在需要你另找的“验证”按钮。

开始后不执行命令、写代码、部署或让开发人员／自动化代做；查找内容、选择图片、切换窗口、等待审核、整理文件及处理错误都不暂停计时。

## 新礼物按这个顺序

1. 点击操作卡“开始礼物任务”，在后台“礼物”中用“新建礼物”填写本次网址标识。**先建规格，再改类型、图片或正文**；未保存的正文会使规格控件暂不可用。
2. 在“规格”里“新增规格”，填 SKU，销售库存策略选“按单准备/采购 · 可重复售卖”，适用艺人选择操作卡指定艺人。先“保存规格”为草稿，再选中这个规格，将状态改为“已启用”并保存。只建一个规格，不填虚构现货库存。
3. 礼物类型选“实体礼物”；选择本次礼物主图，按材料核对品类、组成、交付时间，填写英文全部字段及规格名称，然后“保存新版本”。暂不点击礼物整体的“已启用”。
4. 按下方步骤整理和导入七语；编辑人员逐语言“提交审核”，独立审核人员核对同一最新版本并“批准翻译”。
5. 在“价格”里使用材料指定的市场、币种和金额，设置已经生效的时间、留空可选失效时间。“保存价格新版本”后“发布价格”，在真实价格簿表格确认币种和金额；内容预览不显示商业价格。
6. “检查发布条件”，处理显示的问题；打开双端预览检查图片、七语和规格，再“发布”。首次成功发布会自动启用新礼物。确认结果后回操作卡结束计时。

**库存策略与礼物类型分开选择。** 本任务的实体礼物按单准备、可以重复售卖，不等于有无限现货。

## 七语文件整理：艺人和礼物共用

1. 先把后台“内容语言”切到英语，按操作卡逐字段复制完整英文材料并保存，确保没有未保存的修改；礼物此时必须已有唯一规格和英文规格名称。
2. 展开后台“翻译”，点击“导出翻译包”，保留刚下载的原文件。
3. 返回操作卡“七语文件整理”，选择对应的“艺人”或“礼物”，在“真实导出文件”选刚导出的 JSON，点击“生成本目标七语文件”。下载的是 `uat-translations.json`，请选这次最新下载的文件。
4. 回到同一后台目标和版本，在“导入翻译包”文件框选择生成的文件，等待实际导入校验成功。它形成新草稿，不代表审核或发布完成。
5. 检查英语、简体中文、泰语、越南语、日语、西班牙语、葡萄牙语，按当前版本提交和独立审核。再按任务要求预览、发布。

不用打开 JSON 手改 ID、版本或 hash。文件生成失败时，先核对目标、完整英文、唯一规格和是否使用最新导出包；版本已经改变就重新导出。没有生成或导入成功，不要把该步报告为完成。整理文件也计入 5／8 分钟。

## 超时、失败和结束

完成后选择“我报告已完成”；无法完成选择“实际被阻断”。协助情况如实选择“无协助”“仅独立审核”或“有教练／开发协助”，再点“结束当前任务”。超时后完成也保留真实耗时，不重开一次掩盖第一次结果。重测由准备人安排，旧记录保留。

窗口失效、权限不足、文件被拒或页面报错时，不修改权限或绕过提示。记录阻断发生的步骤和安全错误提示，交给准备人；不要复制浏览器凭据或带授权信息的预览地址。若连计时页都不可用，请向准备人说明，不能补填猜测耗时。

系统只记录耗时和操作结果，始终显示等待独立人工复核。耗时达标、接口成功或你报告完成，都不自动代表验收通过；还需要见证者核对实际操作者、独立审核、画面与发布结果。
