# Daily publication foundation — scoped author evidence

This is implementation evidence, not a complete management-center acceptance or production release claim.

## Explicit boundary

`DIRECT_OPERATOR_V1` / proof 3 records one real source locale, original fields, actual operator/session/operation and immutable document/manifest. Existing v1/v2 translation/reviewer tables and publication branches remain separate. Policy/payment publication is excluded. New public content/media locale provenance identifies the source and fallback; no approved translations are fabricated.

The PostgreSQL repository receives the existing SERIALIZABLE client and operation lease digest, reloads its current scoped delegation, and calls real metadata/media, inventory and price adapters. Final content publication and the operation success receipt share that transaction. Prepared assets are actual source uploads and successful processing-job outputs; URLs/object keys do not cross the management publish port. Original text is not shortened; only derived summaries are bounded without splitting surrogate pairs.
